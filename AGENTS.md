# SovraiOS — agent rules

Expo / React Native app that remote-controls Sovra Harness on the desktop. The desktop
contract is canonical: [SovraHarness `docs/remote-control.md`](https://github.com/Sovra-AI/SovraHarness/blob/main/docs/remote-control.md). Read `docs/architecture.md`
before touching `src/remote/` or the Rust module.

## Expo has changed — do not trust your training data

Expo ships breaking changes every SDK release. Before writing code that touches an Expo,
EAS or React Native API, read the `expo` major in `package.json` and fetch
`https://docs.expo.dev/versions/v<major>.0.0/` or `https://docs.expo.dev/llms.txt`.

## Commands

```bash
npx expo install <package>   # ALWAYS instead of npm add — SDK-compatible versions
npm run check                # tsc + eslint + jest + cargo test — must pass before done
npm run native:android       # rebuild Rust transport + bindings (needs NDK, cargo-ndk)
npm run android              # dev build (Expo Go cannot load the Rust module)
```

## Rules

- `android/` and `ios/` are generated (Continuous Native Generation). Never edit them;
  configure through `app.json` and config plugins.
- Routes live in `src/app/`; non-route code stays outside it.
- **Protocol logic is pure TypeScript in `src/remote/`** and takes a `PhoneTransport`.
  The Rust crate only moves bytes. Keep it that way: decisions in Rust can't be tested by Jest.
- **Never replay input.** Only `stale_observation` may be retried. Mutations need a revision
  from an inspection taken immediately before, in the same session.
- **Never log, store or route the pairing link.** No analytics on it, no navigation params,
  no clipboard leftovers.
- Wire changes: copy the desktop fixtures into `src/remote/__tests__/fixtures/` and keep
  `wire.test.ts` byte-equal. Keep `iroh` pinned to the desktop's version.
- The files in `modules/sovra-remote/{src,cpp,android,ios}` and `*.podspec` are generated by
  `ubrn`; regenerate, don't hand-edit. Never commit `jniLibs/`, `*.a` or `*.xcframework`.
- Styling: tokens only from `src/theme/tokens.ts` (ported from the desktop; see
  `docs/theming.md`). 44pt touch targets, accessible labels/roles on every control.
- Commits use gitmoji (`✨ feat(remote): …`) and update `CHANGELOG.md` under `[Unreleased]`.
